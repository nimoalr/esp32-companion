# esp32-companion

Experimental project to render a cute companion on a Waveshare ESP32-S3.

* [`eyes-demo/`](eyes-demo/README.md): ESP-IDF 5.5 firmware for the
  ESP32-S3-Touch-AMOLED-1.75 that renders two animated cartoon eyes on the
  round AMOLED and cycles expressions on tap. Custom fixed-point rasteriser,
  dirty-rectangle QSPI updates, TE-locked 60 fps. Hardware notes in
  [`eyes-demo/docs/hardware.md`](eyes-demo/docs/hardware.md).
