  1. Close serial monitors, connect USB, then choose the ESP32 above.

  3. Label a run below, start recording, then start the track. Mark anything odd as it happens.

Stereo recording saves both microphones plus features—about 4.1 MB/minute. Untick stereo before connecting for features only (240 KB/minute). When finished, click Disconnect. You can also tap the screen or hold PWR for 2 seconds to exit. “End run” finishes one track but leaves capture mode on for the next.
